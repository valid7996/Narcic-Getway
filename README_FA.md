# اصلاحات Aether در نرسیس

فقط فایل‌های تغییرکرده/جدید اینجاست؛ ساختار پوشه‌ها همان ساختار پروژه است، روی پروژه کپی کنید.
(همین تغییرات به شکل `narcic-aether-fix.patch` هم هست: `git apply narcic-aether-fix.patch`)

## باگ‌های هسته / اتصال
1. **تداخل پورت**: پروکسی خروجی Xray روی 10891 بود، همان پورتی که هسته برای Psiphon/Tor/تونل می‌گیرد (۱۰۸۹۰ به بعد). حالا `AETHER_SOCKS+3 = 10893` (مثل PattNG).
2. **کلمه‌ی `shipped`**: پروفایل `--psiphon-server-entries shipped` می‌نوشت و عیناً به هسته می‌رفت (هسته دنبال فایلی به نام shipped می‌گشت). حالا با فایل لیست سرورها جایگزین می‌شود، یا اگر لیستی نبود پرچم حذف می‌شود. (`PsiphonServerList.kt` جدید، با راستی‌آزمایی امضای Psiphon)
3. **آماده‌بودن سایفون**: پورت سایفون قبل از ساخت تونل به SOCKS جواب می‌دهد؛ برنامه زودتر «متصل» می‌شد. حالا منتظر خط `psiphon is ready` از هسته می‌ماند.
4. **Command دستی**: اگر listener یا log-level نداشت، هسته روی پورتی بالا می‌آمد که برنامه نگاه نمی‌کرد. حالا اضافه می‌شود.
5. دیتابیس سایفون سشن و اسکن/ثبت کلید جدا شد (قفل مشترک).
6. **صفحه‌ی کلیدهای WARP**: آدرس ثبت‌نام، fragment، ECH، fingerprint، finalMask و dialMode جمع می‌شدند ولی هرگز به هسته نمی‌رسیدند. حالا می‌رسند.
7. فیلد **MASQUE SNI** در پروفایل ذخیره نمی‌شد؛ حالا می‌شود.

## UI (فقط بخش Aether)
- همه‌ی متن‌های انگلیسیِ سخت‌کد شده فارسی‌پذیر شد (Other settings، Target strategy، Bundled list، Clear cache، پیام‌های اسکن و کلید و ...).
- عنوان تکراری «Log» حذف شد؛ منوی کشور سایفون مثل صفحه‌ی Psiphon شد (با پرچم).
- فیلد Command دیگر کهنه نمی‌شود (قبلاً فقط با چند فیلد به‌روز می‌شد) و فرمان هم‌ارزِ تنظیمات به‌عنوان «سفارشی» ذخیره نمی‌شود.
- اعتبارسنجی مثل PattNG: Tor/Psiphon دور تونل نیاز به MASQUE دارد؛ Tor و Psiphon فقط تو در تو؛ پل شخصی بدون خط پل. دکمه‌ی ذخیره با دلیل غیرفعال می‌شود.
- صفحه‌ی کلیدها کیبورد را نمی‌پوشاند (imePadding)؛ دیالوگ مرده‌ی `AetherKeysDialog` حذف شد.

## کار دستی که لازم است

- Gradle اینجا نبود: کد را کامپایل/اجرا نکردم. تست جدید: `AetherCommandsTest`.
- `app/libs/zedcore.aar` در زیپ نبود (برای Xray/Psiphon مستقل لازم است).
